# Security policy

DeskGuest is software people trust to let someone help them on their own
computer, so security reports are treated as the most important mail we get.

## Reporting a vulnerability

Please report security problems **privately**, never as a public issue:

- Use GitHub's private vulnerability reporting on this repository
  (the "Report a vulnerability" button under the Security tab), or
- Start a private conversation via the repository's Discussions page asking
  for a private channel, without posting the details publicly.

Please include what you found, what it lets someone do, and how to reproduce
it if you can. A report that is honest about what is proven and what is a
suspicion is more useful than a polished one.

## What to expect

- Your report is read by the project's support team.
- Confirmed problems are fixed as a priority, and the fix ships with a note
  crediting the report (unless you ask not to be named).
- DeskGuest has no telemetry, so a report package is only ever what a user
  chose to send: the in-app Report flow scans the package for passwords,
  keys, and tokens before anything is attached, and nothing is sent until
  the user presses Send.

## Supported versions

DeskGuest is in development and has no public release yet. When releases
begin, this page will state exactly which versions receive security updates.
