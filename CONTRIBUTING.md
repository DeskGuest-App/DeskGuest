# Contributing to DeskGuest

Thank you for wanting to help. DeskGuest is a community project, developed
in the open.

## Ways to help

- **Report a bug** — open an issue with the Bug report template. If the app
  showed you an error screen, its Report button prepares a diagnostics
  package with the details; the template explains how to attach it.
- **Suggest a feature** — open an issue with the Feature request template,
  or float the idea first in Discussions.
- **Ask a question** — Discussions, Q&A category. There are no silly
  questions; DeskGuest is designed for people who know nothing about it.
- **Send code** — fork, branch, and open a pull request. Small, focused
  changes are easiest to review.

## Ground rules

- **Consent is the product.** DeskGuest never connects quietly, never hides
  a session, and never makes STOP hard to reach. Contributions that weaken
  those guarantees will not be merged, at any policy level.
- **No telemetry.** Contributions may not add analytics, tracking, or
  phone-home behaviour.
- **Plain language.** User-facing words are written for a person who has
  never seen the product. If a term needs explaining, explain it where it
  appears.
- **Honest states.** The app says what it knows and admits what it doesn't.
  Error messages state the actual problem, never a vague "something went
  wrong."

## Building

- Windows: `windows/AcpWindows.slnx` (.NET 10).
- Android: see `android/build-manual.sh` and the scripts alongside it.
- Website: `website/` is plain static files — open `website/index.html`.
