DeskGuest downloads — coming Q1 2027

DeskGuest is free, with no account. DeskGuest launches in Q1 2027, and downloads are not open yet — when they open, this page is where they will live, so you always know you have the real thing.

Windows

Windows — Full Platform

For Windows 11 (see support below). The full DeskGuest: get help, give help, Rooms, and unattended access to your own devices where you allow it. Any helper is always named on screen.

Not open yet. When downloads open, this button gets the Windows Full Platform from the project's releases page, with its File Check Code beside it.

Windows — Quick Fix

A small one-session helper for Windows 11. Your helper gives you a one-time code, you get help while you watch, and nothing is installed or left behind. It can never be reached unattended.

Not open yet. When downloads open, this button gets Quick Fix for Windows from the project's releases page.

Hear when downloads open

Every release will be published on the DeskGuest releases page on GitHub. We keep no mailing list, and there is nothing to sign up for here — no email to hand over, no account with us. If you have a GitHub account, Watch the project and GitHub will tell you when a release lands (you can watch for releases only). Prefer a feed reader? Subscribe to the releases feed (Atom) instead.

How much space and memory it needs

Measured on Windows 11 with release candidate v0.0.1; final numbers may change. These numbers are for DeskGuest itself.

Space and memory needs
WhatMinimumRecommended
Free disk space1 GB free2 GB free
Memory (RAM)8 GB16 GB
Processor4-core x86-646-core x86-64
The optional local-model pack is separate. The pack that lets a helper run AI models on your own machine needs about 31 GB — allow 40 GB free on its drive. It is not included in the numbers above, and DeskGuest works without it.

When downloads open, every release will publish a File Check Code (SHA-256) next to its downloads. After downloading, you compare the code for your file with the published one — if they match exactly, the file is the file that was published. How to check, step by step
