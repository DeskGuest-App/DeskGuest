How much space and memory it needs

Measured, not guessed. These numbers are for DeskGuest itself, on Windows 11.

WhatMinimumRecommended
Free disk space1 GB free2 GB free
Memory (RAM)8 GB16 GB
ProcessorAny modern 4-core x86-64 processor6 cores
The optional local-model pack is separate. The pack that lets a helper run AI models on your own machine needs about 31 GB — allow 40 GB free on its drive. It is not included in the numbers above, and DeskGuest works without it.

Check your download (File Check Code)

When downloads open, every release will publish a File Check Code (SHA-256) next to its downloads. After downloading, you can compare the code for your file with the published one — if they match exactly, the file is the file that was published.
