Check a DeskGuest download

Choose or drop the installer you downloaded, then paste the File Check Code published beside the download. The check runs in your browser and the file never leaves your device.

DeskGuest is in pre-release. There is no public installer yet, so there is nothing to check yet. When the first release is published, its File Check Code will appear beside the download, and this page will tell you how to check it.

1. Drop the DeskGuest installer here, or choose it. 2. Paste the published File Check Code. 3. Compare.

No file chosen yet. The check runs entirely on this device — nothing is uploaded.

On Windows

Step 1

Open PowerShell

Press the Windows key, type PowerShell, and open it. No administrator rights are needed.

Step 2

Run the check

Type Get-FileHash, a space, then drag the downloaded file into the window to fill in its path. Press Enter.

Step 3

Compare

PowerShell shows the file's code in the Hash column. Compare it with the File Check Code published beside the download. Upper and lower case don't matter; every letter and digit must match.

What the result means

The codes match

Your file is byte-for-byte the file the code was published for. It is safe to install.

The codes don't match

Do not install the file. Delete it and download again from the Download page or DeskGuest releases on GitHub, nowhere else. If a fresh download still doesn't match, report a mismatched download or email support@deskguest.app.

Only two places are official: this website's Download page and the DeskGuest project on GitHub. DeskGuest is not offered in any app store, and no other site is authorized to offer it. A "DeskGuest" download from anywhere else is not DeskGuest.

The File Check Code is a SHA-256 hash computed from the file itself. Change one byte and the code changes completely. A match means your file is identical to the one the code was published for. Always take the code from deskguest.app or the GitHub project, not from the site you downloaded from.
