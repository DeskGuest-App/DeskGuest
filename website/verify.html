On Windows

Step 1

Open PowerShell

Press the Windows key, type PowerShell, and open it. No administrator rights are needed.

Step 2

Run the check

Type Get-FileHash, a space, then drag the downloaded file into the window to fill in its path. Press Enter.

Step 3

Compare

PowerShell shows the file's code. Compare it, character for character, with the File Check Code published beside the download. They must match exactly.

What the result means

The codes match

Your file is byte-for-byte the file that was published. The file matches the published File Check Code.

The codes don't match

Do not install the file. Delete it and download again from this site or the project's releases page — nowhere else. If a fresh download still doesn't match, report it: that's exactly the kind of thing we need to hear.

Only two places are official: this website's Download page and the DeskGuest project on GitHub. DeskGuest is not in the Microsoft Store or Google Play, and no other site is authorised to offer it. A "DeskGuest" download from anywhere else is not DeskGuest.

Why a code and not just trust? Because trust should be checkable. The code is computed from the file itself — change one byte and the code changes completely — so a match is proof, not a promise.
