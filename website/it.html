Architecture in one paragraph

No DeskGuest cloud and no DeskGuest account: identity is a key held on the device, with a recovery key (Windows) or a 34-word recovery key sheet (Android) as the only way back in — there is no central reset. Devices pair with one-time codes (10-minute expiry, single use). Some connection paths use a third-party coordination service (for example Tailscale) for device discovery only; it never holds sessions or records.

Consent floor — not configurable

Presence (the connected helper is named on every screen), a STOP that always works, refusal to type credentials, and an Activity Record that can't be quietly edited are properties of the product, not settings. Policy governs comfort and scope — it cannot switch the floor off, including any form of unattended access.

Policy & Effective Policy

Rules are written as sentences with scope and source, inherited workplace → group → device. The Effective Policy view shows the resolved result for a given device ("what actually applies"), not just the rule stack. Camera viewing, patch approvals, and auto-remediation are policy-governed and audited; patch rollouts are approval-gated and halt themselves on failure.

Records & exports

The Activity Record lives on the device and accounts for what DeskGuest itself did — what was looked at, sent, and changed. Exports are local files (including CSV) produced on the device. Endpoint backup destinations are your own storage. Compliance evidence packs list their contents before export.

Deployment shapes

Standalone per device, or a workplace hub run once by the organization with sites enrolling by code. There is no DeskGuest-imposed user limit and no device limit. Offboarding is one removal action with the blast list shown first; removing a fellow admin takes dual control, and the last admin cannot be removed.

Security disclosure

Report vulnerabilities privately via GitHub private vulnerability reporting on the DeskGuest project: open a private security advisory. Downloads — and the File Check Code (SHA-256) for each — live only at the DeskGuest project.
