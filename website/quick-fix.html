Quick Fix: one-time help, nothing left behind

Pre-release: DeskGuest v0.0.1 is a release candidate and has not been publicly released yet. This page describes how Quick Fix is designed to work.

For the "my device is doing something weird" moments. DeskGuest: Quick Fix is a tiny, separate way in — built for people who have never installed anything, and a one-time session never becomes standing access.

Two ways to join

It starts with a one-time code from your helper. What happens next depends on how much help you need; each way below says what it can and can't do.

Way one: right in the browser

Open the session link and you're in — no download, no install, no account. You get live view, voice, text chat, and a guide mode where your helper can point at things on the shared screen. One limit, stated on the start screen: a web page cannot be driven at the operating-system level, so this way is guide-and-show. Your helper can see and talk you through it — they cannot take control here.

Way two: one more tap, full help

When watching isn't enough, one tap brings in a one-time helper program — a disposable runner, not an install. It needs no admin rights for a standard session, runs the full session including control under the full presence rules, and removes itself completely when the session ends — no program, no access, nothing installed left behind.

The code

Enter the code, and see who's here

Before anything happens you see your helper's name and face — the same name and face their pairing carries everywhere. No name, no session.

One Allow

You let them in

One explicit Allow starts the session. A fresh, random one-time code belongs to this session alone — single-use, with a 10-minute window to join.

Hang up

It removes itself

When the session ends, the code dies with it and the helper program deletes itself. The code works once. It can't be reused, and it never becomes standing access.

Designed against phone scams

One-time help tools are the scammer's favourite prop, so Quick Fix is designed against that from the first screen.

DeskGuest will never call you

That sentence lives on the Quick Fix start screen, where the person being helped can't miss it: DeskGuest will never call you, and will never ask for this code by phone. A real session is one you started, with someone you chose. Is this a scam?

An extra check, when you want it

For first contact or anything sensitive, either side can ask for the picture-and-word check: the same picture and word appear on both screens, and you confirm it out loud through a channel you already trust before control begins. It's an optional extra assurance — never a mandatory step that makes honest help slower.

Attended only, always

Quick Fix sessions happen with the helped person present. There is no unattended mode, no standing grant, and no re-entry with an old code. By default there's no hard time limit on a session either. The person being helped can end it at any time with the on-screen STOP or Ctrl+Alt+Shift+F9. Control changes hands only through Give control / Take control.

After the session

After the session, a plain-language record stays on your device: who helped, what they did — the Activity Record every DeskGuest session writes. To report a session, use the report form; nothing is sent anywhere automatically. The Terms of Service (v1.0) are public. A start-screen summary links to the full text.

After the session: Quick Fix may offer "Keep DeskGuest on this device" — for people who'll want help again. It's a separate, deliberate enrollment act by the device's owner. Never a default, never silent, and declining it changes nothing about the session that just ended.
